# Problem Definition

## Problem Statement

Students and job seekers often need to evaluate a large number of job opportunities to determine which positions are suitable for their education, work experience, and technical skills. Existing job search platforms provide access to job advertisements, but identifying the degree of compatibility between an individual profile and the requirements of a specific position can still require significant manual effort.

The main problem addressed by this thesis is the development of a web-based system that can automatically compare a user's profile with job requirements and provide meaningful information about their compatibility with available positions.

The proposed system will consider the user's education, work experience, and technical skills when analysing job opportunities. In addition to recommending suitable positions, the system will calculate a compatibility score and identify missing skills that may prevent the user from fully meeting the requirements of a particular job.

## Aim of the Thesis

The aim of this thesis is to design, implement, and evaluate an intelligent web-based job and skill recommendation system that assists students and job seekers in identifying relevant employment opportunities and understanding the skills required to improve their suitability for those opportunities.

## Objectives

The main objectives of the project are

1. To investigate existing job recommendation and matching approaches.

2. To define the functional and non-functional requirements of the proposed system.

3. To design a suitable system architecture and relational database structure.

4. To develop a web-based application using React for the frontend and Python with FastAPI for the backend.

5. To implement persistent data storage using PostgreSQL.

6. To develop a method for comparing user profiles with job requirements.

7. To calculate a compatibility score for available job opportunities.

8. To identify missing skills between a user's profile and job requirements.

9. To develop a recommendation mechanism for ranking relevant job opportunities.

10. To evaluate the functionality, usability, performance, and recommendation quality of the developed system.

11. To investigate whether natural language processing or machine learning techniques can improve job description analysis and job recommendations.
